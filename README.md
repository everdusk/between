# Between

Личный дневник для подготовки к еженедельной психотерапии. Данные хранятся только в браузере (`localStorage`) — без аккаунта и бэкенда.

## Возможности (v1)

- **Дневник дня** — дата, шкала настроения, текст, опциональные темы/теги
- **Недельный обзор** — сводка за текущую неделю, повторяющиеся темы, заметка «говорить на сеансе»
- **Итоги сеанса** — обсуждение, инсайты, домашка; список прошлых сеансов

Интерфейс на русском; название продукта — **Between**.

## Запуск

```bash
npm install
npm run dev -- --port 43123
```

Откройте [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Стек

Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui.

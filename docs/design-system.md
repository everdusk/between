# Between — дизайн-система

Контракт интерфейса Mini App. Новые экраны собираются из этих поверхностей и токенов. Новый цвет, радиус или тип кнопки сюда не добавляют, пока не обновлён этот файл и `src/app/globals.css`.

Источник правды по значениям — код. Этот документ говорит, **что брать** и **чего не выдумывать**.

| Что | Где |
| --- | --- |
| Токены, стекло, ink, утилиты | `src/app/globals.css` |
| Кнопки, поля, бейджи, вкладки | `src/components/ui/` |
| Переключатель | `src/components/ui/switch.tsx` |
| Дата и время | `src/components/theme-date-input.tsx` |
| Тема Telegram | `src/lib/telegram.ts` → `applyTelegramTheme` |
| Цвета чувств | `src/lib/spectrum.ts` |
| Шрифты | `src/app/layout.tsx` |
| Строки | `src/lib/messages/` — 12 каталогов, ключи из `ru.ts` |

## Характер

Светлая морская гамма: пена и камень. В коде зафиксировано, чего не делать: не фиолетовый, не крем с терракотой.

Одна колонка, `max-w-lg`. Это Telegram Mini App, не десктопный журнал. Снизу плавающий док, контент не должен прятаться под него: у оболочки нижний отступ с `env(safe-area-inset-bottom)`.

На экране одна тёмная **ink**-плитка. Она держит фокус: бриф, ближайший сеанс, пэйволл. Остальное — стекло на открытом фоне, без карточки-обёртки на всю вкладку.

Голос интерфейса короткий, на «вы». Новые строки кладут во все 12 каталогов. Арабский и фарси — `dir=rtl`, отступы через логические `ps` / `pe` / `ms` / `me`, не через `left` / `right`.

## Тема Telegram

Вне Telegram цвета берутся из `:root` в `globals.css`.

Внутри Telegram `applyTelegramTheme` перезаписывает токены из `themeParams`. Стекло считается от них через `color-mix`, поэтому плитки и док повторяют тему клиента. Градиент фона в Telegram выключается, остаётся сплошной `bg_color`.

| Токен | В Telegram |
| --- | --- |
| `--background`, текст страницы | `bg_color`, `text_color` |
| `--muted-foreground` | `hint_color` |
| `--primary`, `--primary-foreground` | `button_color`, `button_text_color` |
| `--card` | `section_bg_color`, иначе `secondary_bg_color` |
| `--border` | `section_separator_color`, иначе `hint_color` |
| `--destructive` | `destructive_text_color` |
| `--muted`, `--secondary`, `--accent`, `--input` | фон панели (`panelColor`) |

Правила, которые легко сломать:

- Переопределения стекла и ink для `html[data-telegram-theme]` живут **вне** `@layer`. Внутри `@layer base` они проиграют `:root`.
- Системная тёмная тема браузера не учитывается. Тёмный вид — только `colorScheme` Telegram или яркость `bg_color`.
- **Ink в светлой теме не следует за клиентом.** Это фиксированный тёмно-зелёный акцент бренда. В тёмной теме Telegram ink собирается: 80% фона и 20% текста.
- **Цвета чувств не следуют за темой.** Десять значений в `spectrum.ts` держат ось «слева легче, справа тяжелее». Новое чувство добавляют туда и в пикер, а не локальным `style`.
- Пятна `.atmosphere-blob*` в Telegram приглушены до opacity 0.2. Их оттенок остаётся морским и в компоненты не копируется.

## Поверхности

Класс на секцию. Не собирать тень и blur заново в компоненте.

| Класс | Когда |
| --- | --- |
| `glass` | Обычная плитка: форма, список, день, напоминания. |
| `glass-strong` | Hero экрана, если он не ink: дата в дневнике, спектр недели. |
| `glass-chrome` | Плавающий хром. Сейчас — только док вкладок. |
| `ink` | Одна плитка на экран. Текст внутри: `text-ink-foreground`, подписи `text-ink-muted`. Кнопка на ink — `Button` с `className` на `bg-ink-foreground text-ink`, не `variant="default"`: primary в Telegram может совпасть с фоном плитки. |
| `eyebrow` | Мелкая подпись над заголовком: `0.6875rem`, semibold, tracking `0.16em`, капс. |
| `tabular` | Числа и время. |
| `font-display` | Бренд и заголовки. Шрифт Literata. Всё остальное — Manrope (`font-sans` на `body`). |
| `native-overlay` | Невидимый нативный `input` / `select` поверх нарисованной пилюли. Паттерн даты, времени и языка. |

Радиус плитки — `rounded-3xl`. Вложенный блок — `rounded-2xl`. Контрол (кнопка, чип, поле, док) — `rounded-full` или `rounded-2xl` у поля.

Воздух: плитка `p-5 sm:p-6`, между плитками `space-y-4` или `gap-4`. Не возвращать плотный `space-y-2` как основной ритм экрана.

Пустое состояние — пунктир `border-dashed border-[color:var(--glass-border)]`, текст по центру, без иллюстрации.

## Контролы

Брать компоненты из `src/components/ui/`. Сырой `<button>` допустим только для чипа, который не является кнопкой действия (выбор чувства, день недели, фильтр темы).

| Компонент | Как использовать |
| --- | --- |
| `Button` | `default` — главное действие экрана, одно. `secondary` — сохранить второстепенное. `ghost` — отмена и иконка-действие. `ink` — редкое тёмное действие на стекле (плюс в backlog). Размеры: `default` 40px, `lg` 48px на всю ширину формы, `sm` рядом с текстом, `icon` / `icon-sm` для карандаша и корзины. |
| `Input`, `Textarea` | Уже 44px и `rounded-2xl`. У `Textarea` ставить `resize-none`. |
| `Label` | Над полем, цвет приглушённый. Не дублировать заголовок секции. |
| `Badge` | `secondary` — чувство на записи, с точкой `feelingFill`. `outline` — тема. `default` — выбранный фильтр, если это не свой чип. |
| `Tabs` | Оболочка: `TabsList variant="dock"`. Обычный `default` — сегмент внутри плитки (режим сеанса собран вручную по тому же приёму). |
| `Switch` | Напоминания. Под капотом нативный checkbox, подпись в `label`. |
| `ThemeDateInput` | Всегда с `display` — локализованная строка. Нативный пикер остаётся, видимый текст не отдавать браузеру: он рисует дату в своём формате и чёрным. |

Состояние «сохранено» — короткая вспышка с иконкой `Check` на 1.8 секунды, цвет `text-primary`. Отдельный тост не заводить.

Фокус: `focus-visible:ring-4 focus-visible:ring-ring/25`. Не рисовать свой outline.

## Цвет чувства

`feelingFill(feeling)` из `src/lib/spectrum.ts`. Порядок оси, слева направо: радость, спокойно, усталость, пусто, грусть, тревожно, напряжение, стыд, злость, тяжело.

- Чип в пикере: точка этого цвета. Выбранный чип — `bg-foreground text-background`, не заливка цветом чувства.
- Запись дневника: кромка `inset-y` цветом первого чувства.
- Колонка спектра и полоса долей: те же заливки, включая `UNMARKED_FILL` для заметки без отметки.
- «Тяжело» в пикере нет. Цвет остаётся для старых записей.

## Оболочка экрана

Смотреть `src/components/therapy-app.tsx`.

1. Шапка: Literata «Between», приветствие `text-xs text-muted-foreground`, пилюля языка (`Languages` + подпись + `native-overlay` на `<select>`).
2. Контент вкладки без общей карточки. Заголовок экрана: `eyebrow` и `font-display` около `2.125rem` / `leading-[1.05]`.
3. Док фиксирован снизу, `variant="dock"`, три вкладки с иконками Lucide: `PenLine`, `Waves`, `CalendarDays`. Активная — тёмная пилюля.
4. Подвал со статусом синка — мелкий трекинг, не конкурирует с доком.

Иконки только из `lucide-react`. Размер по умолчанию задаёт кнопка; в чипе и подписи — `size-3` / `size-4` и `aria-hidden`.

## Движение

Пятна фона `drift` 24–30s. Полоска загрузки `loading-slide` 1.1s. Вход вкладки — `animate-in fade-in slide-in-from-bottom-2 duration-500`. Нажатие контрола — `active:scale-[0.97]` или `0.98`.

`prefers-reduced-motion: reduce` уже гасит пятна и полоску загрузки. Новую бесконечную анимацию добавлять рядом с этим правилом.

## Чего не добавлять по дороге

- Вторую палитру, градиентный текст, цветную тень, эмодзи вместо иконок.
- Шкалу настроения 1–10. Чувства — слова, можно несколько.
- Карточку вокруг всего экрана.
- Вторую ink-плитку на том же экране.
- Сырой `oklch(...)` в компоненте. Исключение — спектр чувств и пятна атмосферы.
- Свой календарь вместо `ThemeDateInput`.
- PDF, шаринг с терапевтом, аккаунт вне Telegram. Этого нет в продукте, дизайн их не рисует заранее.
